## 📖 Overview

PARFAIT Logistics는 창고 및 물류 업무를 위한 **Warehouse Management System(WMS)** 프로젝트입니다.

단순한 CRUD 프로젝트가 아닌 실제 물류 업무 프로세스를 기반으로

- 품목 관리
- 거래처 관리
- 재고 관리
- 입고 / 출고 관리
- 물류 데이터 관리

를 구현하는 것을 목표로 개발하고 있습니다.

현재는 Vue 3 기반 프론트엔드부터 구축하고 있으며,
향후 Spring Boot API 및 MySQL을 연동하여 실제 서비스 형태로 확장할 예정입니다.

# 🎯 Project Goals

이 프로젝트는 단순한 Vue CRUD 프로젝트가 아닌

실제 물류 회사에서 사용하는 WMS 시스템을 목표로 개발하고 있습니다.

향후 구현 예정 기능

- 창고 관리
- 입고 관리
- 출고 관리
- 재고 이력
- 배송 관리
- 수출입 관리

를 통해 실제 업무 프로세스를 구현할 계획입니다.
